# Validation Instructions: Django ToDo App in Kubernetes

Ця інструкція описує кроки, необхідні для розгортання інфраструктури та перевірки працездатності додатку.

## 1. Розгортання кластера та ресурсів

Для автоматичного створення кластера `kind` та застосування всіх маніфестів виконайте скрипт:

\`\`\`bash
bash bootstrap.sh
\`\`\`

## 2. Перевірка статусу подів

Переконайтеся, що всі поди успішно перейшли у стан `Running`. Особливу увагу зверніть на базу даних: вона має бути повністю готова (`READY 1/1`) завдяки налаштованим `readinessProbe` та `livenessProbe`.

\`\`\`bash
# Перевірка подів бази даних
kubectl get pods -n mysql

# Перевірка подів веб-додатку
kubectl get pods -n todoapp
\`\`\`
*(Примітка: замініть назви неймспейсів на власні, якщо вони відрізняються).*

## 3. Валідація підключення до бази даних

Щоб перевірити, чи успішно додаток прочитав змінні середовища з `Secret` та встановив з'єднання з 0-індексованим подам бази даних (`mysql-0`), перегляньте логи Deployment:

\`\`\`bash
kubectl logs -l app=todoapp -n todoapp
\`\`\`
Ви не повинні бачити помилок доступу (`Access Denied`) або тайм-аутів з'єднання.

## 4. Перевірка роботи додатку (UI / API)

Щоб отримати доступ до веб-інтерфейсу з локального комп'ютера, налаштуйте прокидання портів (Port Forwarding):

\`\`\`bash
# Якщо у вас є сервіс для додатку:
kubectl port-forward svc/<назва-сервісу-додатку> 8080:8080 -n todoapp

# Або напряму до пода додатку:
kubectl port-forward pod/<назва-пода-додатку> 8080:8080 -n todoapp
\`\`\`

Після цього відкрийте у браузері адресу: [http://localhost:8080](http://localhost:8080)
